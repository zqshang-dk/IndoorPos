# 数据格式

## base-station-location.txt

| 列号 | 描述 |
| --- | --- |
| 1 | 基站编号 |
| 2-3 | 纬度、经度，单位：度 |
| 4 | 高程，单位：米 |

## range.txt

| 列号 | 描述 |
| --- | --- |
| 1 | 时间，单位：秒 |
| 2-5 | 距离，单位米，分别相对基站1、2、3、4 |

## range-with-height.txt

| 列号 | 描述 |
| --- | --- |
| 1 | 时间，单位：秒 |
| 2-5 | 距离，单位米，分别相对基站1、2、3、4 |
| 6 | 高程测量值，单位米 |
